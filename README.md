## ⭐ Main project: ThinkPal

**ThinkPal** is my AI chat platform that brings many AI models and tools into one app. A public link is coming soon.

- 💬 Real-time streaming chat across multiple AI providers, including OpenAI, Gemini, Anthropic, xAI and Groq
- 🎨 Text-to-image (DALL·E, Hugging Face) and image-to-text with GPT-4 Vision and OCR
- 🔊 Text-to-speech with ElevenLabs and AWS Polly, including multilingual and cloned voices
- 🧑‍💻 Markdown, code, math and diagram rendering in replies
- 🌦️ Weather lookups, and the ability to create your own custom AIs
- 🔐 Google OAuth sign-in, chat history saved to Firebase, and Cloudinary media storage
- 💳 Subscriptions and billing with Stripe and Lemon Squeezy

**Built with:** React · Vite · Redux Toolkit · TanStack Query · Tailwind CSS · Vercel AI SDK · Firebase · Stripe
